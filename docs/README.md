## 🎯 Project Overview

**Scroma** is a browser-based screenshot mockup tool designed to help content creators, developers, and marketing professionals create professional mockups without design expertise.

### Key Goals

- Enable users to create professional screenshot mockups in under 2 minutes
- Achieve 1,000 active users within 6 months with 5% freemium-to-paid conversion
- Support batch processing and team collaboration workflows
- Generate $5K MRR within 6 months scaling to $25K MRR within 12 months
- Enable AI-powered features for enhanced productivity

### Tech Stack

- **Framework:** Next.js 15 + TypeScript
- **Build Tool:** Next.js 15 with Turbopack
- **Styling:** Tailwind CSS 4 + shadcn/ui
- **State Management:** Zustand 5
- **Routing:** Next.js App Router
- **Animation:** Framer Motion 12
- **Testing:** Vitest 3 + Testing Library
- **API Routes:** Next.js API routes for AI integration
