## Risk Coverage

- **Tool Version Compatibility**: Covered by unit tests for Next.js 15 config validation
- **Development Environment Differences**: Covered by E2E tests across environments
- **Build Performance**: Covered by SSG performance testing in E2E scenarios

## Recommended Execution Order

1. P0 Unit tests (ESLint, Prettier, path aliases, Next.js config validation)
2. P0 Integration tests (Turbopack HMR, shadcn/ui, Next.js app health)
3. P0 E2E tests (Next.js dev server startup)
4. P1 tests (App Router structure, git setup, SSG build process)
5. P2 tests (CSS features, gitignore rules, script validation)
