# Story 1.1: Project Setup & Infrastructure

## Status

Draft

## Story

**As a** developer,
**I want** to establish the Next.js 15 development environment and project foundation,
**so that** I can build the screenshot mockup tool with optimal performance and modern tooling.

## Acceptance Criteria

1. Next.js 15 project initialized with React 19 and TypeScript configuration
2. Tailwind CSS integrated with custom design tokens for colors and spacing
3. ESLint and Prettier configured with Next.js 15 best practices
4. Git repository initialized with proper .gitignore and branching strategy
5. Basic folder structure created (app/, components/, hooks/, utils/, types/, lib/)
6. Development and build scripts functional with Turbopack hot-reload working
7. Basic health check page displays "Scroma - Screenshot Mockup Tool" via SSG
8. API routes structure created in app/api/ for future AI integration
9. next.config.js configured for SSG export and Fabric.js compatibility

## Dev Notes

### Next.js 15 Configuration Details

**Tech Stack** [Source: ui-architecture/frontend-tech-stack.md]:

- **Framework**: Next.js 15.0.0 with App Router, SSG, Turbopack, and API routes
- **UI Framework**: React 19.1.0 with React Compiler optimizations
- **Styling**: Tailwind CSS 4.1.13 with 5x faster builds and cascade layers
- **Build Tool**: Next.js + Turbopack for lightning-fast builds and SSG optimization
- **State Management**: Zustand 5.0.8 (will be added in Story 1.4)

**Project Structure** [Source: ui-architecture/project-structure.md]:


**Environment Configuration** [Source: ui-architecture/environment-configuration.md]:

- **Canvas Settings**: Max file size 10MB, default canvas 1200x800
- **Performance Settings**: 60fps target with 16ms render throttle
- **Development Tools**: Turbopack enabled, DevTools integration
- **Next.js Variables**: Use NEXT*PUBLIC* prefix for client-side variables

**Development Standards** [Source: ui-architecture/frontend-developer-standards.md]:

1. **Default to Server Components** - Use Server Components by default, add 'use client' only when needed
2. **Leverage App Router conventions** - Use page.tsx, layout.tsx, loading.tsx, error.tsx appropriately
3. **Use TypeScript strict mode** - Enable all strict compiler options
4. **Configure Turbopack optimally** - Use experimental Turbopack features for maximum speed

**Key Configuration Files**:

**next.config.js** [Source: ui-architecture/environment-configuration.md#187]:

```javascript
/** @type {import('next').NextConfig} */
const nextConfig = {
  experimental: {
    turbo: {
      rules: {
        "*.svg": { loaders: ["@svgr/webpack"], as: "*.js" },
      },
      resolveAlias: {
        canvas: false,
        fs: false,
        path: false,
        os: false,
      },
      moduleIdStrategy: "deterministic",
      memoryLimit: 4096,
    },
    optimizePackageImports: ["fabric", "konva", "react-konva"],
    serverActions: true,
    ppr: true,
  },
  images: {
    formats: ["image/avif", "image/webp"],
    minimumCacheTTL: 60 * 60 * 24 * 7,
  },
  compiler: {
    removeConsole: process.env.NODE_ENV === "production",
    reactCompiler: true,
  },
};
```
